# アフターAI

知人から勧められて、そのまま貸してもらった一冊。

## 感想

なんかAIの利用を煽るような書き出しから始まる。生成AIの話をしていると思えば、ただのレコメンドシステムも「AI」だと言い出しており、おそらく意図的な混同だと思うがちょっと胡散臭い本。まあ語りたいことは「人間がやっておらず自動化されている」ということだと思うが、はるしネーションのリスクがある生成AIと、従来の機械学習やレコメンドエンジンでは全く論点が異なってくるのに、随分と雑な話を展開したものだと感じた。

あまりに書いてあることが適当で乱暴だと感じたので途中で読むのをやめてしまったが、各章の内容は基本的に「僕が考えた生成AIの各領域への導入方法」だった。
具体的な現場の導入ハードルへの苦しみに触れているケースはなかったのが残念で、「こういう問題があるから、なんとかする必要がある」で終わっていて、さすがに浅いし、ぱっと見でも指摘できていない課題がゴロゴロしている話が多かった。
ベンチャーで１から業務設計するならともかく、大企業を想定していると書かれている本なのだから、そのあたりは期待外れと言える。もちろん全企業に適用できるパターンなんてあるはずもないが、１事例を添えるだけでも説得力は違っただろうので、残念である。
